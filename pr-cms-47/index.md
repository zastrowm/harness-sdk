# Strands Agents

> Strands Agents is the open source toolkit for building production AI agents in Python and TypeScript. It runs in your process with no hosted Strands control plane.

## Start here

- [Documentation](http://github.programdotrun.com/harness-sdk/pr-cms-47/docs/user-guide/sdk/quickstart/overview/index.md): Choose a model provider and build your first agent.
- [Harness quickstart](http://github.programdotrun.com/harness-sdk/pr-cms-47/docs/user-guide/harness/quickstart/index.md): Start with a fully assembled agent.
- [Strands Box](http://github.programdotrun.com/harness-sdk/pr-cms-47/box/index.md): Strands Box runs AI agents in a sandbox that limits the files, programs, websites, and credentials they can access locally or in supported cloud deployments.
- [Strands Decider](http://github.programdotrun.com/harness-sdk/pr-cms-47/decider/index.md): Strands Decider routes, classifies, and scores known outcomes with a decision model that returns typed answers and probability signals without generating text.
- [Build with AI coding agents](http://github.programdotrun.com/harness-sdk/pr-cms-47/docs/user-guide/build-with-ai/index.md): Install the Strands plugin for Claude Code, Codex, or Cursor.
- [Examples](http://github.programdotrun.com/harness-sdk/pr-cms-47/examples/): Explore complete agent examples.
- [Frequently asked questions](http://github.programdotrun.com/harness-sdk/pr-cms-47/faq/index.md): Get practical answers about choosing, building, evaluating, and deploying with Strands.
